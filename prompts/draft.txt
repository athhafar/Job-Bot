TUGASMU:
1. Analisis apakah postingan Threads ini BENAR-BENAR lowongan pekerjaan, tawaran proyek freelance, atau peluang kerja untuk mobile developer (Flutter, Android Kotlin, React Native).
   - Nilai FALSE jika ini adalah orang yang sedang MENCARI kerja (job seeker/open to work), diskusi teknologi biasa, tutorial/sharing, atau spam.
2. Berikan skor relevansi (1-10) terhadap keahlian mobile developer pada profil di atas:
   - 8-10: Sangat relevan dengan Flutter / Kotlin / React Native.
   - 6-7: Cukup relevan (mobile general / tech stack irisan).
   - 1-5: Kurang relevan / bukan peluang mobile dev.
3. Jika is_opportunity = true dan skor relevansi >= 6, buatkan:
   - summary: Ringkasan 1 kalimat jelas tentang pekerjaan/proyek, budget/gaji (jika ada), dan kriteria utama yang dicari.
   - comment_draft: Komentar balasan publik di Threads yang sangat singkat (MAKSIMAL 2 kalimat). Nada ramah, profesional, cocok untuk kultur Threads, menyebutkan 1 keahlian paling relevan, dan mengajak melanjutkan via DM. Tidak lebay, tidak terdengar seperti bot.
   - dm_draft: Pesan langsung / DM yang lebih lengkap (MAKSIMAL 5 kalimat). Berisi: sapaan ramah, perkenalan singkat 1 kalimat, 1 bukti pengalaman/proyek nyata dari profil yang selaras, link portofolio/GitHub, dan ajakan sopan untuk mendiskusikan kebutuhan proyek lebih lanjut.
4. ATURAN PENTING:
   - Gunakan BAHASA YANG SAMA dengan bahasa postingan (jika postingan berbahasa Inggris, tulis summary & draft dalam bahasa Inggris; jika bahasa Indonesia, tulis dalam bahasa Indonesia).
   - JANGAN mengarang teknologi atau pengalaman yang tidak tercantum di profil pengembang.
   - Balas HANYA objek JSON valid tanpa markdown formatting atau penjelasan tambahan.
